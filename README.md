# 교실 소음 측정기

마이크로 교실 소리를 재서 계기판과 흐름 그래프로 보여주고, 제한선을 넘으면 화면에 경고를 띄우는 교실용 웹앱입니다. 설치 없이 브라우저에서 바로 씁니다.

**바로 쓰기:** https://earnjay12.github.io/noise-meter/

## 사용 순서

1. **마이크 켜기**를 누르고 브라우저의 마이크 허용을 누릅니다.
2. **제한선**을 정합니다. 지금 교실 소리보다 10 정도 높게 잡으면 적당합니다.
3. **목표**를 고릅니다.
   - 🚗 조용히 채우기: 조용한 동안 자동차가 달려서 깃발까지 가면 성공. 시끄러우면 급정거합니다
   - 💣 폭탄 해체: 제한선을 넘는 동안 도화선이 타고 폭탄이 떨립니다. 다 타면 펑, 시간을 버티면 해체 성공
   - 📊 측정만: 목표 없이 소리와 경고만 표시
4. **경고** 문구와 경고음을 정하고 **시작하기**를 누릅니다.

측정 화면에서는 `Space` 키로 일시정지, `F` 키로 전체화면을 켤 수 있습니다. 설정은 브라우저에 저장되어 다음에도 그대로 남습니다.

## 알아둘 점

- PC 마이크로 재는 값은 전문 소음계와 다릅니다. **보정** 슬라이더로 휴대폰 소음계 앱과 비슷하게 맞춰 쓰세요.
- 마이크가 없는 곳에서 화면만 보려면 **마이크 없이 시험하기**를 켜면 가짜 소리로 움직입니다.
- 경고음과 효과음은 외부 파일 없이 브라우저가 직접 만듭니다.

## 파일

- `index.html` 설정 화면과 측정 화면
- `style.css` 화면 꾸밈
- `app.js` 마이크 측정, 목표·경고 판정, 계기판과 그래프 그리기
- `effects.js` 폭탄 장면(도화선·폭발), 자동차 도로, 축포. 모두 캔버스로 직접 그림
- `mock.html` 방향을 정할 때 썼던 초기 시안 (계기판형 / 장면형 비교)
- `effects-demo.html` 효과만 따로 눌러 볼 수 있는 시안 페이지
